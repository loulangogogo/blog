# in/not in 包含于/不包含于

这个表示某个字符串 包含于/不包含于 另外的一个字符串，类似java字符串包含方法

```python
name = "loulan"
print('lou' in name)
print("xxx" in name)
print("lou" not in name)
print("xxx" not in name)

#True
#False
#False
#True
```

# [x:y] 截取字符串

这个操作类似java字符串的截取操作方法，只是操作方式不一样

> [x:y] 表示截取从x位开始，截取到y之前（y-1）
>
> [x:] 表示从x开始截取到结束
>
> [:y] 表示从0开始截取到（y-1）
>
> **正数表示从左往右数，如果出现负数直接到了最后的从右往左**
>
> **这个时候就出现了一个步长的概念，默认情况下步长是1，所有数据的截取都是从左往右，也就是说左边的数据必须小于右边的数据**

> **如果步长是负数，那么数据的截取就会变成从右往左，右边的数据必须小于左边的数据**

```python
name="中华人民共和国"
print(name[1:4])
print(name[:4])
print(name[1:])
print(name[-1:-4])
print(name[-1:-4:-1])
print(name[-4:-1])
#华人民
#中华人民
#华人民共和国
#
#国和共
#民共和
```
