# 一、字符串前缀

| 前缀        | 全称             | 返回类型 | 用途                                     | 常用程度 |
| ----------- | ---------------- | -------- | ---------------------------------------- | -------- |
| 无          | 普通字符串       | `str`    | 最普通的字符串                           | ⭐⭐⭐⭐⭐    |
| `r` / `R`   | Raw String       | `str`    | 原始字符串，不处理反斜杠转义             | ⭐⭐⭐⭐⭐    |
| `f` / `F`   | Formatted String | `str`    | 格式化字符串，可嵌入表达式               | ⭐⭐⭐⭐⭐    |
| `b` / `B`   | Bytes Literal    | `bytes`  | 字节串                                   | ⭐⭐⭐⭐     |
| `u` / `U`   | Unicode Literal  | `str`    | Python 2 兼容，Python 3 中基本无实际作用 | ⭐        |
| `rf` / `fr` | Raw + Formatted  | `str`    | 原始字符串 + 格式化                      | ⭐⭐⭐      |
| `rb` / `br` | Raw Bytes        | `bytes`  | 原始字节串                               | ⭐⭐       |



# 二、占位符

### 占位符总表

| 格式符 | 类型   | 说明                      | 示例             | 输出           |
| ------ | ------ | ------------------------- | ---------------- | -------------- |
| `s`    | 字符串 | 字符串                    | `f"{'abc':s}"`   | `abc`          |
| `d`    | 整数   | 十进制整数                | `f"{123:d}"`     | `123`          |
| `b`    | 整数   | 二进制                    | `f"{10:b}"`      | `1010`         |
| `o`    | 整数   | 八进制                    | `f"{10:o}"`      | `12`           |
| `x`    | 整数   | 十六进制（小写）          | `f"{255:x}"`     | `ff`           |
| `X`    | 整数   | 十六进制（大写）          | `f"{255:X}"`     | `FF`           |
| `c`    | 整数   | Unicode 字符              | `f"{65:c}"`      | `A`            |
| `e`    | 浮点   | 科学计数（小写）          | `f"{12345:e}"`   | `1.234500e+04` |
| `E`    | 浮点   | 科学计数（大写）          | `f"{12345:E}"`   | `1.234500E+04` |
| `f`    | 浮点   | 定点小数                  | `f"{3.14159:f}"` | `3.141590`     |
| `F`    | 浮点   | 与 `f` 类似（特殊值大写） | `f"{3.14:F}"`    | `3.140000`     |
| `g`    | 浮点   | 自动选择 `f` 或 `e`       | `f"{12345:g}"`   | `12345`        |
| `G`    | 浮点   | 自动选择 `F` 或 `E`       | `f"{12345:G}"`   | `12345`        |
| `%`    | 浮点   | 百分比                    | `f"{0.123:%}"`   | `12.300000%`   |
| `n`    | 数值   | 本地化数字格式            | `f"{123456:n}"`  | 与地区设置有关 |

### 对齐方式

| 写法 | 含义               | 示例             | 输出   |
| ---- | ------------------ | ---------------- | ------ |
| `<`  | 左对齐             | `f"{'abc':<10}"` | `abc`  |
| `>`  | 右对齐             | `f"{'abc':>10}"` | `abc`  |
| `^`  | 居中               | `f"{'abc':^10}"` | `abc`  |
| `=`  | 符号后补齐（数字） | `f"{-42:=6}"`    | `- 42` |

### 宽度控制

| 写法 | 说明     | 示例            | 输出       |
| ---- | -------- | --------------- | ---------- |
| `5`  | 最小宽度 | `f"{12:5}"`     | `12`       |
| `10` | 最小宽度 | `f"{'abc':10}"` | `abc`      |
| `20` | 最小宽度 | `f"{123:20}"`   | 前面补空格 |

### 填充字符

> 填充字符 + 对齐方式

| 写法   | 示例              | 输出         |
| ------ | ----------------- | ------------ |
| `*<10` | `f"{'abc':*<10}"` | `abc*******` |
| `*>10` | `f"{'abc':*>10}"` | `*******abc` |
| `*^10` | `f"{'abc':*^10}"` | `***abc****` |
| `0>8`  | `f"{123:0>8}"`    | `00000123`   |

### 数字符号

| 写法 | 含义                   | 示例        | 输出  |
| ---- | ---------------------- | ----------- | ----- |
| `+`  | 总显示正负号           | `f"{10:+}"` | `+10` |
| `-`  | 仅负数显示负号（默认） | `f"{10:-}"` | `10`  |
| 空格 | 正数前留一个空格       | `f"{10: }"` | `10`  |

### 千位分隔符

| 写法 | 示例             | 输出        |
| ---- | ---------------- | ----------- |
| `,`  | `f"{1234567:,}"` | `1,234,567` |
| `_`  | `f"{1234567:_}"` | `1_234_567` |

### 精度控制

| 写法  | 示例               | 输出    |
| ----- | ------------------ | ------- |
| `.2f` | `f"{3.14159:.2f}"` | `3.14`  |
| `.3f` | `f"{3.14159:.3f}"` | `3.142` |
| `.0f` | `f"{3.8:.0f}"`     | `4`     |

### 字符串

| 写法 | 示例               | 输出    |
| ---- | ------------------ | ------- |
| `.3` | `f"{'Python':.3}"` | `Pyt`   |
| `.5` | `f"{'Python':.5}"` | `Pytho` |

### 百分比

| 写法  | 示例             | 输出         |
| ----- | ---------------- | ------------ |
| `%`   | `f"{0.123:%}"`   | `12.300000%` |
| `.2%` | `f"{0.123:.2%}"` | `12.30%`     |

### 禁止转换

| 写法 | 示例         | 输出       |
| ---- | ------------ | ---------- |
| `b`  | `f"{255:b}"` | `11111111` |
| `o`  | `f"{255:o}"` | `377`      |
| `x`  | `f"{255:x}"` | `ff`       |
| `X`  | `f"{255:X}"` | `FF`       |

### 科学计数法

| 写法  | 示例              | 输出           |
| ----- | ----------------- | -------------- |
| `e`   | `f"{123456:e}"`   | `1.234560e+05` |
| `.2e` | `f"{123456:.2e}"` | `1.23e+05`     |
| `E`   | `f"{123456:E}"`   | `1.234560E+05` |
