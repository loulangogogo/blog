# for

> for 变量 in 可迭代数据：
>
> ​	执行语句

### fori 功能实现

```python
# range指定的是数字的范围，
# 单个数字 range(5) 表示 [0,5)
# 两个数组 range(1,5)表示[1,5)
# 三个数字 range(1,10,2) 表示[1,10) 步进是2
for j in range(1,5):
    print(j)
```

python的这种功能写法就相当于java的fori的写法

```java
for(int j=1;j<5;j++)
  printf(j);
```

### iter

```python
name='loulan'
for j in name:
    print(j)
    
# l
# o
# u
# l
# a
# n
```

这种迭代的写法就类似java的iter

```java
char[] name = {'l', 'o', 'u', 'l', 'a', 'n'};
for (char o : name) {
    System.out.println(o);
}
```
