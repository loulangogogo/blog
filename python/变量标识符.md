# 疑问

> 1. 为什么python定义变量接受数据的时候不需要设置类型？
> 2. 类型都不知道的变量怎么进行的运算（加减乘除）的？
> 3. 数据是怎么销毁的（GC）

# 解答

## 1. 动态类型语言

python是属于动态类型的语言，变量的类型是在运行时决定的。**变量**只是一个标识符，一个名字，它指向的是一个对象，也就是说，**变量在内存中存储的不是数据，而是数据对象所在的地址**（类似java引用类型变量，而且比java宽泛）。

而数据对象是一个指定的数据结构存储在内存中的（数据结构中包含数据类型，数据值，以及垃圾回收信息等）。

```TEXT
java 分为基础数据类型和引用数据类型。
基础数据类型是直接存储在变量的栈中的。
引用数据类型就是先存储一个对象，然后变量存储对象的地址，java的引用类型只能引用相同对象的类型
```

> 虽然python没有固定的类型，但是可以进行类型注解
>
> ```python
> name: str = "Tom"
> age: int = 18
> ```
>
> ```python
> def add(a: int, b: int) -> int:
>     return a + b
> ```
>
> 这些只能是类型提示，python解释器不会强制检查

## 2. 计算

python进行变量的加减乘除计算的时候是按照类似下面的步骤进行的：

1. 找到变量a
2. 通过变量a存储的地址找到数据对象
3. 查看对象的类型
4. 判断给对象的类型是否能进行当前运算（不能就抛出异常错误）
5. 调用该类型的计算函数进行计算
6. 对计算结果产生新的数据结构对象
7. 返回对象的引用

因此，同样的计算，python的执行路径要复杂的多（这就是为啥比java慢的一个原因吧）

```text
java的计算要直接简单的多，例如 a+b

CPU直接：
	load int
	add
	store int
	
然后就计算完成了，几乎没有额外的开销
```

```text
python计算 a+b

① 找到变量 a
        ↓
② 得到对象地址 0x1000
        ↓
③ 查看对象类型（int）
        ↓
④ 找到 int 的加法实现
        ↓
⑤ 找到变量 b
        ↓
⑥ 查看对象类型（int）
        ↓
⑦ 执行整数加法
        ↓
⑧ 创建新的 int 对象 30
        ↓
⑨ 返回对象引用
```

> java在编译的时候就知道哪里有错误，类型对不对。属于编译型语言。
>
> python在执行的时候才知道有没有错误，类型不对直接抛出。属于解释性语言。

## 3. 对象销毁（引用计数、循环垃圾回收）

在python的数据对象结构里面有一个引用计数的属性，这个属性用来判断当前数据对象是否被引用，没有请用就释放内存。

但是，如果出现数据对象循环引用的情况，那么引用计数永远不会变成0。（类似死锁）

所以python增加了 **循环垃圾回收** 来专门处理这种情况。

### 引用计数

```text
	对象创建
      │
      ▼
	引用计数 +1
      │
      ▼
引用计数是否为0？
      │
 ┌────┴─────┐
 │          │
 否         是
 │          │
继续存在   立即释放内存
```

这种情况下的python大量对象清除的很快，不用等GC。（这也是与java的最大区别之一）

### 循环垃圾回收

当出现了数据对象互相引用的情况：

```text
A对象
↑  ↓
B对象
```

那么这个时候的引用计数永远都无法变成0。

>这个时候就需要 python 周期性的检查是否有相互应用的对象而且没有外部的引用，如果存在那么就进行GC。

>[!IMPORTANT]
>
>GC的触发有手动和自动。
>
>手动： gc.collect()
>
>自动：根据具体的阈值和触发策略进行回收，这些阈值和策略可能随着 python 版本的变化而变化。

> [!WARNING]
>
> 从 Python 3.12 开始，引入了 **Immortal Objects（永久对象）（PEP 683）**。
>
> ```text
> None
> True
> False
> 0
> 1
> 2
> 3
> ""
> "abc"
> ```
>
> 
>
> 例如：
>
> ```
> a = 3
> ```
>
> 这里的 `3` 不是普通对象，而是：
>
> ```
> Immortal Integer
> ```
>
> 它的引用计数已经不是"真实引用数"了。
>
> 官方为了避免频繁修改这些常量对象，把它们标记为：
>
> ```
> IMMORTAL
> ```
>
> 意思应该类似常量，不用进行清除的数据对象。
>
> > [!NOTE]
> >
> > 其他的数据类型，尤其是自定义数据类型还是正常计数的。
> >
> > ```python
> > import sys
> > a=[1]
> > print(sys.getrefcount(a))
> > ```
> >
> > 使用这个代码可以获取计数
