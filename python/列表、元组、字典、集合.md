# 列表 list

> [1,2,"a"]
>
> 通过 **中括号** 来进行表示列表

python 的列表有点类似 java 里面的 list 集合，只不过 python 可以设置各种不同的数据类型，java 只能设置同一数据类型，如果硬要设置不同数据类型，那么就是 List<Object>



# 元组 tuple

> (1,2,'a')
>
> 通过 **小括号** 来进行表示
>
> - 只能在初始化的时候设置值
> - 不允许增删改
> - 只能查

python 的元组目前没有和 java 正常的对比，如果硬要对比就是数组。只不过元组不允许增删改。

# 字典 dict

> {key:value, key:value}
>
> 通过 **大括号** 里面是 **键值对** 的方式来进行表示

python 的字典 dict 类似于 java 的 HashMap 集合，可以设置不同的数据类型类似 Map<Object,Object>

# 集合 set

> {1,2,"a"}
>
> 通过 **大括号** 来进行表示
>
> 也可以通过 a=set(),来初始化设置集合

python 的 set 集合和 java 的 Hashset 集合差不多,也是不允许数据的重复的。
