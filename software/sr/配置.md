# 首页配置

### 1. 代理服务

可以手动添加代理服务，代理服务的方式有多种，自己的认识的也就 shell、SSH、Socks5，其他的就不怎么熟悉了。

### 2. 全局路由配置

> **配置**
>
> - 一般采用“配置”的方式进行路由，配置文件地址自己写的 https://loulangogogo.github.io/blog/software/sr/loulan.conf 
>
> - 上面这个采用的是无策略分组的配置方式，后期可以再配置一个策略分组的配置方式

> **代理**
>
> 代理的话就和配置没有什么关系，相当于所有经过的流量都自动采用代理服务器

# 设置

### 1. 代理类型

> 代理 -> 代理类型 选择 none 模式
>
> - 其中的区别可以查看使用手册中的说明

### 2. 隧道

> 隧道的功能可以选择性开启，看说明文档的意思，开启这个相当于开启了一个虚拟网卡，所有的电脑流量基本都会从这个虚拟网卡通过，然后使用配置的规则进行流量的划分。
>
> - 目前碰到采用 SSH 代理流量时候，结果代理通了，但是代理服务器局域网的其他服务器结果不能使用，然后开启这个隧道就可以正常使用了

### 3. GeoLite2 数据库

因为在配置文件中使用国家 IP 路由规则的配置，一般这个数据库默认使用的是 shadowrocket 内置的，我们可以通过这个来使用自己配置的数据库。这里有两种方式的配置

> **第一种**
>
> maxmind，这个我也进行了账号的注册，但是好像使用起来没有那么方便

> **第二种**
>
> 配置连接 https://github.com/Loyalsoldier/geoip/releases/latest/download/Country.mmdb
>
> 然后进行更新数据库就可以了。
>
> 根据目前查看，这个库的代码更新还是挺频繁的，所以使用这个比较好一点。
