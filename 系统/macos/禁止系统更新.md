macOS 默认会自动检查系统更新，但**不会像 Windows 一样强制安装**。如果你想禁止 macOS 自动更新（例如避免爱思助手、系统助手类软件提示升级，或者避免 macOS 自动下载大版本更新），可以分几个层级处理。

## 1. 关闭 macOS 系统自动更新（推荐）

打开：

**系统设置 → 通用 → 软件更新 → 自动更新（ⓘ）**

关闭：

- ❌ 检查更新
- ❌ 下载新的更新
- ❌ 安装 macOS 更新
- ❌ 安装来自 App Store 的应用更新
- ❌ 安装安全响应和系统文件

路径：

```
 → 系统设置 → 通用 → 软件更新 → 自动更新
```

这是苹果官方支持的方式。

------

## 2. 终端彻底关闭自动更新检查

打开 Terminal：

```bash
sudo defaults write /Library/Preferences/com.apple.SoftwareUpdate AutomaticCheckEnabled -bool false
```

关闭自动下载：

```bash
sudo defaults write /Library/Preferences/com.apple.SoftwareUpdate AutomaticDownload -bool false
```

关闭自动安装：

```bash
sudo defaults write /Library/Preferences/com.apple.SoftwareUpdate AutomaticallyInstallMacOSUpdates -bool false
```

查看当前状态：

```bash
defaults read /Library/Preferences/com.apple.SoftwareUpdate
```

------

## 3. 禁止 macOS 自动下载大版本升级

例如 macOS 26 不希望自动下载 macOS 27：

执行：

```bash
sudo defaults write /Library/Preferences/com.apple.SoftwareUpdate DisableOSUpgradeNotifications -bool YES
```

同时可以关闭升级提示：

```bash
sudo softwareupdate --ignore "macOS"
```

不过注意：

> macOS Ventura 13.4 之后，`softwareupdate --ignore` 已经被苹果限制，不再像旧版本那样完全有效。

查看：

```bash
softwareupdate --list
```

------

## 4. 禁止爱思助手（i4Tools）自动升级

如果你说的是：

> 爱思助手安装后，总提示 iOS 固件升级 / macOS 客户端升级

这个不是 macOS 系统更新，而是爱思助手自己的后台服务。

处理：

### 方法一：关闭登录启动

打开：

```
系统设置
→ 通用
→ 登录项
```

查看：

```
允许在后台运行
```

关闭：

- 爱思助手
- i4Tools Helper
- Aisi Assistant Helper

------

### 方法二：删除后台启动项

查看：

```bash
ls ~/Library/LaunchAgents
```

和：

```bash
ls /Library/LaunchAgents
```

查找：

```bash
aisi
i4
xiyou
```

例如：

```bash
rm ~/Library/LaunchAgents/com.aisi.helper.plist
```

然后重启。

------

## 5. 禁止 App Store 自动更新

关闭：

```bash
系统设置
→ App Store
```

关闭：

```
自动更新
```

也可以：

```bash
defaults write com.apple.appstore AutomaticDownload -bool false
```

## 6. 企业环境更彻底的方法（MDM）

如果是公司 Mac，可以使用 MDM：

例如：

- Jamf
- Mosyle
- Kandji

策略：

```
Restrictions
 └── Software Update
      ├── Disable automatic updates
      ├── Delay major updates
      └── Defer updates
```

可以延迟：

- 小版本更新最多 90 天左右
- 大版本更新更久

## 推荐配置（个人 Mac）

你的情况（MacBook Pro + 开发环境）我建议：

| 项目                      | 建议     |
| ------------------------- | -------- |
| 关闭自动下载 macOS 大版本 | ✅        |
| 关闭自动安装              | ✅        |
| 安全响应更新              | 保留开启 |
| App Store 自动更新        | 关闭     |
| 爱思助手后台启动          | 关闭     |
| 手动检查更新              | 每月一次 |

不要完全屏蔽系统更新，因为 macOS 的：

- WebKit 安全漏洞
- Gatekeeper
- XProtect 恶意软件库

仍然会通过系统更新机制维护。

如果你使用的是 **macOS 26**，还可以进一步通过 `profiles` 配置延迟系统更新，比 `defaults` 更稳定。
